AxiCMD is the command palette of the Axpert Web shell. Users type commands such as `view`, `edit`, `create`, `configure` or `sdk` and get ranked, token-by-token suggestions. Selecting a suggestion opens the form, report or builder in the shell.

This site documents how AxiCMD works, for the people who build and maintain it.

<Callout type="info" title="Source of truth">
  The code is the source of truth. Each page names the file it describes. When a page and the code disagree, the code
  wins; please fix the page.
</Callout>

## The repository at a glance

| Path | What it holds |
| --- | --- |
| `AxpertPlugins/AxiCMD/HTMLPages/js/axicmdmain.js` | The engine: one large script that parses tokens, resolves entities, ranks suggestions and runs commands. |
| `AxpertPlugins/AxiCMD/Structures/Postgre/Scripts` | Database scripts for PostgreSQL. |
| `AxpertPlugins/AxiCMD/Structures/Oracle/Scripts` | The same scripts for Oracle. Keep both sets in sync. |
| `AxiApi/` | ASP.NET Core (.NET 8) API for command configuration, favourites and user settings. |
| `aspx/mainHomeConfigTemplate.html` | The shell page that hosts the palette and loads `axicmdmain.js?v=N`. |
| `docs/` | ADRs, specs and the refactor plan written alongside the code. |
| `ThirdParty/` | Pinned vendor code. Do not edit. |
